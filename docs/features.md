# 제품 명세 (현재 구현)

앱 이름: **햄핀즈** — 금융 학습 퀴즈 + 게이미피케이션.

## 1. 인증·온보딩

| 기능 | 상태 | 설명 |
|------|------|------|
| 회원가입 | ✅ | 닉네임·이메일·비밀번호 |
| 이용약관·개인정보 동의 | ✅ | 필수 체크, 본문은 임시 (`legal_documents.dart`) |
| 관심 카테고리 선택 | ✅ | 가입 직후, 복수 선택 |
| 로그인 | ✅ | 이메일·비밀번호, salt+SHA-256 |
| 비밀번호 재설정 | ✅ | 가입된 이메일 기준 |
| 테스트 계정 | ✅ | `test@finquiz.com` / `test1234` |
| 소셜 로그인 | ❌ | UI만, 핸들러 스텁 |
| 닉네임 중복 확인 | ❌ | 버튼 스텁 |

상세: [auth.md](./auth.md)

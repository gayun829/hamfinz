# 머리 기준으로 정렬한 햄핀 SVG

18개 완성형 캐릭터. 원본 벡터·색상·내부 비율은 그대로 유지했다.

- 캔버스: 384 × 384, 투명 배경
- 머리 본체: 너비 140.5, 가로 중심 192, 윗선 116
- 모자·귀·더듬이·머리카락은 머리 크기 측정에서 제외
- 머리와 몸을 포함한 전체 캐릭터에 동일한 배율·이동 적용
- 검정 햄핀의 원본 머리는 조금 작아서 같은 머리 너비에 맞게 보정
- SVG는 해상도에 독립적이며 변환값은 manifest.json에 기록
- 모자·옷이 포함된 완성형은 그대로 유지. 별도 장식으로 분해하지 않음
- 원시인(수염 없음) 기존 PNG에 대응하는 새 SVG는 이번 묶음에 없음

source/는 재가공에 필요한 원본이며 정렬된 파일은 assets/figma/shop/skins/에만 보관한다.
중복 normalized 폴더, ZIP, 미리보기 PNG는 저장소에서 제거했다.
현재 상품 분류·가격·세트 구성은 docs/shop-assets-and-catalog.md를 따른다.
